# AI-purge

**跨模型 LLM 安全评估、提示注入研究与对抗测试工作台**

AI-purge 将提示词研究、对抗测试方法、自动变异算法、Agent 安全基准和评估流程整理为统一、可追溯、可复现的研究体系。

> 本项目面向授权测试环境，用于模型与 Agent 安全评估、提示注入防护验证和红队研究。不承诺解除第三方云服务安全策略，不提供针对真实账户或未授权系统的数据窃取、越权执行工具。

## 项目模块

- Prompt Catalog：测试样本、元数据、来源和版本。
- Method Registry：方法原理、适用条件、局限和防御映射。
- Mutation Engine：受约束的改写、重排、格式变换和组合。
- Agent Security：工具调用、间接提示注入、记忆与 RAG 测试。
- Evaluation：统一判定、指标、证据链和回归报告。
- Adapters：接入本地模型、测试服务和授权 API。

## 当前状态

阶段：文档与研究框架初始化。当前提交建立统一术语、目录规范、测试边界和来源索引；不将尚未实现的功能描述为已交付能力。后续代码按模块实现，并以测试和可复现报告证明能力。

## 使用要求

仅在拥有或明确获准测试的模型、应用、数据和环境中使用。优先使用合成数据和专用 canary。不得将真实凭据、个人信息或生产数据放入样本。遵守上游许可证、服务条款和适用法律。
