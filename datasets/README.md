# 数据集与基准目录

采用全量登记策略：包括公开 benchmark、论文附属数据、竞赛数据、合成数据和历史数据。每个数据集单独核对数据卡、许可证、使用条款、敏感内容和再分发限制。

## 已发现的数据集家族

| 数据集/基准 | 研究面 | 记录要求 |
|---|---|---|
| AdvBench | 安全行为评估 | 记录原始来源与访问条款；危险目标仅保留元数据/安全映射 |
| JailbreakBench | 越狱评测 | 固定版本、目标分类、评估协议 |
| HarmBench | 有害行为安全评估 | 分类器、行为定义、数据许可 |
| BIPIA | 间接提示注入 | 载体类型、任务、信任边界 |
| InjecAgent | 工具型 Agent 注入 | 工具权限、任务场景、合成环境 |
| AgentDojo | Agent 攻防基准 | suite、任务、工具环境、防御配置 |
| PromptBench | 提示鲁棒性 | 扰动类型、任务和模型 |
| HackAPrompt | 人类生成的提示注入尝试 | 数据卡、隐私和再分发条件 |
| Tensor Trust | 提示注入攻防游戏 | 样本来源、标注和许可 |
| garak datasets | 探针与检测器数据 | 与 probe 版本绑定 |
| PyRIT seed datasets | 种子提示与目标 | SeedPrompt 元数据、来源和条款 |

## 数据导入流程

1. 先登记数据集 URL、版本和数据卡。
2. 核对代码许可证与数据许可证，二者不可混为一谈。
3. 记录样本字段、规模、语言、标签和已知偏差。
4. 检查个人信息、凭据和高风险可执行载荷。
5. 对不允许再分发的数据仅保存引用和必要元数据。
6. 通过安全审查后才导入合成或获准样本。
7. 保留原始 ID、派生 ID、转换记录和校验哈希。

本仓库当前仅登记基准家族，不代表已经下载、镜像或复现这些数据集。
